# Дипломный проект: Интернет-магазин «Северяночка»
Полнофункциональный интернет-магазин продуктов питания


**Исполнитель:** Томин Вадим Сергеевич, группа 03-23.ИСИП.ОД.11  
**Учебное заведение:** АНПО «Хекслет-колледж»
## О проекте

«Северяночка» — интернет-магазин продуктов питания с адаптивным интерфейсом, личным кабинетом, корзиной, оформлением заказа и административной панелью. Проект выполнен в рамках дипломной работы.

## Технологический стек

| Категория | Технологии |
|---|---|
| **Frontend** | Next.js 15 (App Router), TypeScript, Tailwind CSS, Framer Motion |
| **Backend** | Next.js API Routes, Server Actions |
| **База данных** | PostgreSQL 16 (локально, WSL Ubuntu) |
| **Аутентификация** | JWT, bcrypt |
| **Дополнительно** | pg, rc-slider, react-input-mask, react-share |

## Установка и запуск

### Предварительные требования

- Node.js 18+
- PostgreSQL 16 (локально)
- WSL (для Windows) или нативный Linux

### Шаги по установке

**1. Клонировать репозиторий**
```
git clone https://github.com/TominVadim/delivery-shop.git
cd delivery-shop
```
**2. Установить зависимости**
```
npm install
```
**3. Создать файл .env.local в корне проекта**
```
DB_HOST=localhost
DB_PORT=5432
POSTGRES_USER=postgres
POSTGRES_PASSWORD=123456
DB_NAME=severianochka
NEXT_PUBLIC_BASE_URL=http://localhost:3000
```
**4. Создать базу данных и таблицы**

SQL-скрипты находятся в папке migrations/.

**5. Запустить сервер разработки**
```
npm run dev
```
Приложение доступно по адресу http://localhost:3000

## Основной функционал

- **Адаптивный интерфейс** — mobile (360px), tablet (768px), desktop (1400px)
- **Регистрация и авторизация** — двухэтапная регистрация с верификацией телефона, JWT-токены
- **Каталог товаров** — фильтрация по цене, свойствам, наличию; пагинация
- **Поиск** — выпадающее меню с debounce, отдельная страница результатов
- **Карточка товара** — галерея, цены со скидками, отзывы с рейтингом
- **Избранное** — добавление/удаление, отдельная страница
- **Корзина** — изменение количества, выбор товаров, расчёт бонусов
- **Оформление заказа** — адрес доставки, выбор даты и времени, фейковая оплата
- **Личный кабинет** — аватар, имя, город, карта лояльности, смена пароля
- **Административная панель** — товары (CRUD), заказы, пользователи, статьи, каталог, график доставки

## Роли пользователей

| Роль | Возможности |
|---|---|
| **user** | Покупки, избранное, личный кабинет |
| **manager** | Доступ к админ-панели |
| **admin** | Полный доступ, изменение ролей |

## База данных

Проект использует локальную PostgreSQL вместо MongoDB Atlas. Основные таблицы:

| Таблица | Назначение |
|---|---|
| **products** | Товары (127 записей) |
| **users** | Пользователи |
| **orders** | Заказы |
| **articles** | Статьи блога |
| **catalog** | Категории каталога |
| **reviews** | Отзывы о товарах |
| **cards** | Карты лояльности |
| **delivery_slots** | График доставки |
